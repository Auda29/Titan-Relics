# Inspirations and credits

Titan Relics draws visual inspiration from
[The Archive In Between](https://www.instagram.com/thearchiveinbetween/).
Its depictions of overgrown colossi, titan remains and monumental trees helped
shape the mod's sense of scale, atmosphere and several structure designs.

The Obelisk and Ruined Tower also draw on visual references by **Josh White**.

## Visual references

- [Archaean Colossi, The Archive In Between](https://www.instagram.com/reel/DaoBxUEiBNa/),
  a reference for the large Colossus.
- [Vigilant-Class Archaean Colossi, The Archive In Between](https://www.instagram.com/reel/Da-s0zqi7OQ/),
  a reference for the Small Colossus.
- [D.E.A.D., The Archive In Between](https://www.instagram.com/reel/DXM3J4sgqJl/),
  a reference for the crowned Titan Skull.
- [Skull and sword, The Archive In Between](https://www.instagram.com/reel/Db9KCtWi0eG/),
  a reference for the second Titan Skull. This label describes the referenced
  scene rather than asserting an official work title.
- [World Tree / Gaia's Nursery, The Archive In Between](https://www.instagram.com/reel/DaBgsX0C9s4/),
  a reference for the World Tree.
- [Painted Desert, Josh White](https://www.instagram.com/p/Da0NEq7kUAO/),
  a reference for the Obelisk.
- [Sci-fi animation, Josh White](https://www.instagram.com/reel/DbqXYoVx2hR/),
  a reference for the Ruined Tower.

These credits acknowledge the visual references used during development.
They do not claim endorsement or permission from the referenced creators.
