# Obelisk

The current design is **V3**, a solid tapered square antiprism with a rotated
crown and an eight-block buried foot. Integration into the playable alpha is pending.

- [V3 design and reproduction commands](docs/OBELISK_V3.md)
- [V2 design history](docs/OBELISK_V2.md)
- [Design configurations and outputs](design/README.md)
- [Archaeology, collectible finds, and Colossus expedition maps](gameplay/README.md)

The agreed gameplay direction is an archaeological site at the foot of the
solid monument, with an exclusive collectible and a map to the very rare
Colossus. Detailed layout, reward implementation, and numeric rarity values remain
open; this gameplay is not implemented yet.
