# Titan Relics 0.1.0-beta.1

*Colossal ruins of a forgotten age*

Unreleased candidate. No public beta has been approved or uploaded.
SURVIVAL_ACCEPTANCE: pending

## Changes since Alpha 5.0.5

- Recognized incompatible saved-world environments produce an explained
  rejection and return the client to the menu, preserving the frozen plan.
- Discoveries is the factory preset for new worlds without an existing saved
  installation choice. Existing choices and world plans retain their values.
- The displayed mod name is Titan Relics; registry/save IDs remain `relics`.
- MIT license and source-linked visual inspiration credits are included in new JARs.
- Player installation/usage guides and a structured bug report form are available.

## Install and report problems

Use exactly one JAR for Fabric or NeoForge and Minecraft 1.21.1 or 26.2.
Java 21 is required for 1.21.1 and Java 25 for 26.2. Install the matching
Lithostitched 1.8.0 dependency on all targets, plus Fabric API on Fabric.
Install matching files on the server and player clients. Dependencies are not bundled.

Read the [installation guide](https://github.com/Auda29/Titan-Relics/blob/main/docs/players/INSTALLATION.md)
and [player guide](https://github.com/Auda29/Titan-Relics/blob/main/docs/players/PLAYER_GUIDE.md).
Back up existing saves. A new world gives the full current relic selection;
existing worlds keep their saved plans, even for unexplored chunks. Updates do
not move relics or replenish finite shared loot. No cross-loader save conversion
or 26.2-to-1.21.1 downgrade is provided.

Minimum distances do not guarantee a short journey. DH 3.3.3 FEATURES can omit
relic starts during distant generation; INTERNAL_SERVER passed for newly generated
distant areas. See [compatibility and support boundaries](https://github.com/Auda29/Titan-Relics/blob/main/docs/technical/MOD_COMPATIBILITY.md).

Report bugs through the [issue form](https://github.com/Auda29/Titan-Relics/issues/new?template=bug_report.yml)
with exact versions, reproduction steps and logs.

Before public release, replace the pending Survival marker with the actual
acceptance result and finalize the exact release revision, artifact checksums
and any remaining known issues. Until then the platform upload tool refuses
execution with these notes, even if its upload flag is selected.
