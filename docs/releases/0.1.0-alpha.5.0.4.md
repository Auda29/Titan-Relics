# Relic Mod Alpha 5.0.4

Configure relic generation for each new world, including biome compatibility
with terrain modpacks.

- **Create World → World → Relic generation:** Expedition, Balanced and
  Discoveries presets, editable block distances and per-family percentages.
- **Biome rules per relic:** keep the Standard lists, include matching landscapes
  through common tags and explicit mappings, or select exact biome IDs. Search
  the loaded registry by biome, mod ID or mod display name.
- **Mod-list configuration:** optional Fabric Mod Menu and the NeoForge mod list
  edit personal defaults for future worlds. The former title/options buttons
  are removed. In a running local world, settings and rejection diagnostics are
  read-only; unavailable server settings are explicitly identified.
- **World-scoped persistence:** new worlds save their own density and biome
  settings independently of later default changes. Existing worlds retain their
  frozen plans. No migration or retroactive structure generation is performed.
- **Impossible unique destinations:** if no possible biome permits the large
  Colossus, its destination resolves unavailable instead of searching forever.

The large Colossus remains unique and at least 30,000 blocks from initial spawn.
Biome selection retains terrain and spacing checks; higher opportunity density
does not guarantee finds along a walking route. Modpack coverage and exploration
balance still need broader playtesting.

## Install

Install **one** matching JAR. Minecraft **1.21.1 requires Java 21**; Minecraft
**26.2 requires Java 25**. Fabric requires Fabric Loader, the matching Fabric
API and Lithostitched 1.8.0. NeoForge requires its matching loader and
Lithostitched 1.8.0 for NeoForge, without Fabric API. Mod Menu is optional on
Fabric. Back up saves before upgrading; do not downgrade a world after saving
with the new version.

All four player JARs and `SHA256SUMS.txt` are included. Generation is supported
on the noise-based Overworld; this release does not add custom-generator support.

## Verification

The feature passed all four local player builds and actual dedicated-server
fresh/restart suites. Real Fabric clients on both game versions created worlds
through the vanilla UI and verified scoped density/biome settings, Apply/Cancel,
defaults isolation and read-only diagnostics. NeoForge graphical clients were
compiled but not separately driven. Local production tests include 168,803
settings assertions and the existing planner, search, executor and gameplay
suites; 43 packaging/resource/compatibility/documentation tests passed.

The release workflow rebuilds all four targets, runs its full resource and Java
checks plus a native Fabric 26.2 restart suite, and verifies downloaded assets
against their checksums before publication.
