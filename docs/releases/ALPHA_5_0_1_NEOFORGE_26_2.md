# Relic Mod Alpha 5.0.1 for NeoForge 26.2

Native NeoForge release of the full Alpha 5 gameplay for Minecraft 26.2:
approved interiors, persistent shared distribution/map targets, defense
encounters, personal physical rewards, immediate key payment, finite cores,
per-item held-magnet wear, archaeology and the 80-block Tree aura with
Regeneration II and Resistance II.

Install `relics-0.1.0-alpha.5.0.1+mc26.2-neoforge.jar` with Minecraft 26.2,
Java 25+, NeoForge 26.2.0.88+ and Lithostitched 1.8.0 for NeoForge 26.2.
Install dependencies separately. Fabric API is not required. Use one matching
Relic JAR for your loader and game version.

All 40 original structure templates are retained, including copper chests and
firefly bushes. Native registration, events and persistent attachments drive
the shared gameplay. Animal extras respect native cancellation and population
caps. The player artifact contains no Fabric API or test classes.

Use a fresh native world for the complete Alpha 5 selection. Cross-loader save
conversion is not provided. Server tests use simulated players; graphical
client, shader/LOD and arbitrary modpack acceptance are not claimed for this
new port.
