# Titan Relics 1.0.0-beta.3

*Colossal ruins of a forgotten age*

Beta 3 is an explicitly requested playtest release of the current discovery and
menu changes. It is not a stable release. It is selected as GitHub Latest, as
with Beta 2; Modrinth and CurseForge classify the files as Beta. The source is
from PR #2, which retains its unresolved acceptance findings.

## Changes since Beta 2

- Replaced the initial technical settings pages with three play styles, short
  descriptions and a schematic distribution diagram. The diagram is illustrative,
  not a seed preview or a map of actual structures.
- Moved distances, family shares, biome choices and diagnostics into Advanced
  settings. Switching views preserves unsaved custom edits. Existing worlds
  open with a read-only summary. Includes German/English labels and narration.
- New presets allocate each skull family 15% of opportunities outside Obelisk
  regions and 25% nearby. Suitable classified modpack landscapes are selected
  consistently across sampled footprints.
- Sword Skull relative height tolerance changes from ±4 to ±8 blocks.
- The Colossus checks nearby positions in distance order. Preset minimum
  distances are 4,000 blocks for Discoveries, 8,000 for Balanced and 15,000 for
  Expedition. Terrain may require a farther site. These are not travel guarantees.
- Generation revision 2 uses a new v4 planning policy. Existing world plans,
  rewards and historical generation rules remain unchanged. Old Beta 1 rejects
  v4 plans without rewriting them. There is no retrogen.

## What to test

1. Back up saves and install exactly one matching JAR with its dependencies.
2. Create a **new world with structures enabled**. Open World → Relic generation
   and explicitly select Discoveries, Balanced or Expedition. Previously saved
   installation defaults retain their values until a preset is selected.
3. Check preset selection, the diagram, Advanced settings, view switching,
   Apply and Cancel. Include your GUI scale and resolution with menu feedback.
4. Explore normally and note the chosen preset, travel distances and relic types.
   Inspect the Sword Skull's ground contact, especially in modpack terrain.
5. Report Minecraft/loader/modpack versions, logs, reproduction steps and useful
   coordinates or screenshots through the bug report form.

Updating an existing world does not enable the new distribution, even in its
unexplored chunks. To inspect an old world's settings, open the read-only view.
Do not downgrade a v4 world to an older mod build.

## Known limits and validation

The redesigned menu compiled locally for Minecraft 26.2 and Fabric 1.21.1. Its
real-client test probe was updated and compiled, but the new layout has not yet
received a running-client visual check. The release workflow builds/tests all
eight targets before publishing any GitHub downloads.

One native Living World density comparison completed using the actual supplied
playtest settings as its baseline. A separate Balanced world naturally generated
both skull types and the Colossus. **The complete placement/contact check still
fails**: the Sword Skull has 71 short unsupported ground contacts at the selected
expanded-terrain site. Its 25,149 model blocks match and are protected. This beta
does not claim that the contact issue is fixed. The crowned skull passed.

The Colossus block verifier also reports three intended gameplay-marker
replacements by Vault, Trial Spawner and chest; exact marker normalization in
that verifier remains unfinished. Its ground contact and protection passed.
The planned second native seed and full Survival/long-session acceptance remain
outstanding. DH background generation is not covered by this test release.

See the [native verification report](https://github.com/Auda29/Titan-Relics/blob/v1.0.0-beta.3/docs/testing/SKULL_DISTRIBUTION_BALANCE_20261110.md).
