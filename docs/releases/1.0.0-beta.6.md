# Titan Relics 1.0.0-beta.6

*Colossal ruins of a forgotten age*

Beta 6 introduces **generation revision 4** (`relics-distribution-v6-modded-terrain`)
for newly created worlds to fix extreme relic distances in fragmented and hilly
terrain (such as Terralith and Biomes O' Plenty modpacks) while keeping ground
contacts clean and existing worlds untouched. It is a public Beta, selected as
GitHub Latest. Full Survival and long-session acceptance remain outstanding.

## Changes since Beta 5

- **Center-biome routing & expanded modpack biome tags (Revision 4):** the
  center biome now selects the eligible family profile and Crowned Skull
  palette without rejecting sites near dry biome borders. Ocean and river
  biomes remain excluded across the center and 5×5 dry-land grid. *Matching
  landscapes* recognizes additional convention tags (`c:is_tree/coniferous`,
  `c:is_tree/deciduous`, `minecraft:is_taiga`, `c:is_taiga`,
  `c:is_dry/overworld`, `c:is_mountain/peak`, `c:is_mountain/slope`).
- **Actual geometry & surface-contact validation (Revision 4):**
  - Build-height checks use each rotated template's actual vertical bounding
    box (`minY + 8` to `maxY - 8`), allowing surrounding hills above the center
    ceiling.
  - Each Crowned Skull palette preserves its own relative slope range,
    including the rock palette's `+18` uphill allowance in mountain terrain.
  - World Tree and Sword Skull validate their actual exposed surface-contact
    columns (pre-screened via heightmaps before full column queries) while
    skipping deep buried roots so they may cross caves just like the placement
    processor.
  - World Tree samples a tighter 5×5 dry-land grid (`radius = 56, step = 28`)
    around its grounded root footprint beneath the wider canopy.
- **Higher rare-family ticket shares (Revision 4 presets):** Ruined Tower,
  Small Colossus, and World Tree each rise from `2%` to `4%` of cell
  opportunities (funded from empty tickets).

## Existing worlds and setup

Back up saves and install exactly one matching JAR with its required
dependencies. Existing worlds created on earlier betas keep their frozen
generation revisions (revisions 1–3), planning fingerprints, and interior
revisions even in unexplored chunks—there is no retrogen or automatic world
migration. Create a new world (or select a preset for a new world) to use
revision 4. Do not downgrade worlds to a version that cannot read their saved
revisions.

## Validation and known limits

- **Matched vanilla comparison (Fabric 26.2, Discoveries, seed `731204`):**
  World Tree moved from `73,505` blocks (Rev 3) to `15,149` blocks (Rev 4,
  −79%); Great Colossus moved from `5,063` to `3,340` blocks; Crowned Skull
  stayed at `9,403` blocks; Sword Skull moved from `7,753` to `15,490` blocks
  due to stricter per-column surface-contact enforcement.
- **Matched Terralith + Biomes O' Plenty comparison (Fabric 26.2, Discoveries,
  seed `2090676289`):** World Tree moved from `126,429` blocks (`1,668.8s`) to
  `23,190` blocks (`42.8s`, −82% distance and 39× faster); Crowned Skull moved
  from `26,714` to `18,600` blocks (−30%); Great Colossus stayed at `4,289`
  blocks; Sword Skull moved from `7,664` to `18,552` blocks.
- **Saved-chunk World Tree audit:** checked `33,849` low logs across `4,338`
  low-root columns on a naturally generated Revision 4 World Tree (`0` missing
  root blocks, `0` unexpected ground-level gaps).
- **Automated suites & 8-target matrix:** passed Java worldgen, distribution,
  and gameplay suites, all `200` Python tests, and local build + packaging +
  asset verification across all eight targets. Full release CI validates all
  eight targets before publishing player JARs. Platform moderation and public
  download availability are separate; confirmed platform file IDs and hashes
  are persisted in `platform-upload-state.json`. Full Survival, long-session
  and final menu visual acceptance remain outstanding.
