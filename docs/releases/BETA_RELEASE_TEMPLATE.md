## Install

Download: DOWNLOAD_URL, to be inserted only after verifying published assets.
Choose one JAR for Fabric or NeoForge and Minecraft 1.21.1 or 26.2. See the
[installation matrix](../players/INSTALLATION.md) for exact dependency baselines.
Java 21 is required for 1.21.1; Java 25 for 26.2. Lithostitched 1.8.0 is required
on all targets, Fabric API only on Fabric. Install matching files on the server
and every client. Dependencies are not bundled.

Back up worlds first. A new world is needed for the complete current relic
selection. Existing plans remain frozen even for new chunks. Structures and
shared finite loot are not moved or refilled. Loader conversion and downgrading
a 26.2 save to 1.21.1 are not provided.
