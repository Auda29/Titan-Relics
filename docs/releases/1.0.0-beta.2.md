# Titan Relics 1.0.0-beta.2

*Colossal ruins of a forgotten age*

Second public beta. This is a testing release, not a stable release. It is marked
as the latest GitHub release at the author's request. GitHub requires the normal
release flag for that badge; Modrinth and CurseForge still classify it as Beta.
The full natural Survival playthrough remains outstanding.

## Changes since Beta 1

- Added Minecraft Java 1.21.11 and 26.3 for Fabric and native NeoForge.
- Retained Minecraft 1.21.1 and 26.2 support and their tested dependency pins.
- Adapted version-specific recipes, furnace hooks, biome sampling, world-load
  preparation, placement protection, trim palettes and client menus.
- Expanded release-tag builds and platform uploads to eight verified player JARs.
- Preserved existing registry/save IDs, the forty frozen structure templates,
  finite rewards and world planning rules. No Survival-balance changes are claimed.

## Validation and limits

The new targets passed reproducible builds, production-server gameplay/restart,
seven world-load rejection cases, recovery, natural structure generation and
real client menu checks. See the [port report](https://github.com/Auda29/Titan-Relics/blob/main/docs/releases/JAVA_1_21_11_26_3_PORTS.md).

Back up saves. Use a new world with structures enabled for complete generation.
Cross-loader save conversion and Minecraft downgrades are unsupported. Existing
worlds retain their plans; updates do not move relics or refill finite shared loot.
The new targets have not inherited the earlier shader/modpack acceptance results.
Survival balance, discovery pacing and long-session behavior remain under review.
Read the [player guide](https://github.com/Auda29/Titan-Relics/blob/main/docs/players/PLAYER_GUIDE.md)
and [compatibility notes](https://github.com/Auda29/Titan-Relics/blob/main/docs/technical/MOD_COMPATIBILITY.md).

Report exact versions, logs and reproduction steps through the
[bug report form](https://github.com/Auda29/Titan-Relics/issues/new?template=bug_report.yml).
