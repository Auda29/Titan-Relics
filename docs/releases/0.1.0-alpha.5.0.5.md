# Relic Mod Alpha 5.0.5

The large Colossus minimum distance now follows the preset selected when
creating a world. It can also be edited independently on the distances page.

| Preset | Minimum distance from the original world spawn |
|---|---:|
| Expedition | 30,000 blocks |
| Balanced / Ausgewogen | 15,000 blocks |
| Discoveries / Entdeckungen | 8,000 blocks |

Custom values range from 4,000 to 100,000 blocks and must be at least twice the
minimum distance between relics. The setting applies to the unique destination
search and is saved with each new world. The Colossus remains unique; suitable
biomes and terrain can require a destination farther away than this minimum.
This setting is not a maximum travel distance or a nearest-site guarantee.

Existing worlds retain their saved Colossus destination and search progress.
Older settings files without the new field retain the previous 30,000-block
minimum, even if their other values match Balanced or Discoveries. Select a
preset again in the new-world editor to use its new distance for a new world.

## Install

Install **one** matching JAR. All four targets are included, with SHA-256 checksums:

- Fabric for Minecraft 1.21.1 and 26.2.
- NeoForge for Minecraft 1.21.1 and 26.2.

Minecraft 1.21.1 requires Java 21; Minecraft 26.2 requires Java 25. Fabric needs
the matching Fabric API and Lithostitched 1.8.0. NeoForge needs the matching
Lithostitched 1.8.0 NeoForge build and no Fabric API. Back up saves before an
upgrade. No world reset or relocation of existing relics is performed.

## Verification

All four targets passed local player builds and asset checks. A real Fabric
1.21.1 client verified the new field, preset changes, a custom distance and its
persistence through actual world creation. Isolated Fabric 26.2 servers checked
Balanced and Discoveries through natural generation, maps, locate, datapack
reload and a full restart. The existing Living World planning journal was
additionally read unchanged with the updated code. These checks do not claim
a full new-version modpack playtest or a separately driven NeoForge client.

The tag workflow rebuilds all four targets and runs the resource, planner,
gameplay and native Fabric 26.2 restart checks before publishing the assets.
