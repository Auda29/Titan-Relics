# Magnet und kleiner Koloss: Rückmeldung vom 28. Oktober 2026

Niklas bestätigt den Fund des defekten Magneten im kleinen Koloss, das
Reparaturrezept und die sichtbaren Rezepte im Crafting Book. Diese Rückmeldung
bestätigt die vorhandene Mechanik; sie verlangt keine Änderung der Zutaten
oder der zehnprozentigen Fundchance pro kleinem Koloss.

## Neue Verbrauchsregel

Der Magnet soll ab jetzt pro erfolgreich eingefügtem Item zählen. Ein
64er-Stack kostet 64 Punkte; eine Teilaufnahme kostet die tatsächlich eingefügte
Menge. Anziehen allein oder eine fehlgeschlagene Aufnahme kostet nichts.
Eine magnetisch unterstützte Einfügung überschreitet das verbleibende Budget
nicht. Bei null verbleibenden Punkten endet die Unterstützung, normales
Aufheben bleibt möglich. Die Kapazität bleibt bei 1.000, beide Hände bleiben
unterstützt, ungewählte Inventarplätze bleiben inaktiv. Der Tooltip nennt
nun verbleibende Items. Die vorherige Regel pro Stack ist damit abgelöst.

## Neuer Fundort

Die einzige Truhe im kleinen Koloss soll an das obere Ende der zweiten Treppe
versetzt werden. Dort bekommt sie einen kleinen Maschinenaufbau ähnlich dem
Armfundstand des großen Kolosses. Deckel, Bedienfläche und Weg müssen frei von
generiertem Terrain bleiben. Neue Exporte ersetzen keine bisherigen Dateien.
Die gestalterische Arbeit ist einem GPT-6-Astra-Worker mit `high` zugewiesen.
Die anschließende technische Integration wird gesondert geprüft.
