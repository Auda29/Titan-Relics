# Titan Relics screenshot library

The shared source for the README, German/English website and platform galleries.
All 31 selected views are here, including the previous published images and ten new captures.

Minecraft Java 1.21.1 with TerraVista Living World and shaders. The modpack adds terrain, vegetation and lighting. The filenames below name the actual subjects, including the author-corrected identifications.

Gallery PNGs are 960 × 527 and below 2 MB each. The original 960:527 aspect ratio is preserved. Older HUD overlays are cropped in both dimensions. New HUD-free captures only receive proportional resizing. There are no generated, retouched, colour-graded or brightened image elements.

The author-selected [Colossus title original](originals/2026-11-10-colossus-selected-front.png) and [Sword Skull night original](originals/2026-11-10-sword-skull-night.png) are retained byte-for-byte, with their original HUD. The website keeps its selected Colossus title photograph and CSS framing.

## Capture context

- Earlier morning captures on 10 November come from the Beta 1 playtest.
- Afternoon captures on 10 November come from the Beta 3 playtest.
- Captures on 11 November come from the development playtest of the new generation revision. They are not claimed as captures from the published Beta 3 build.
- The new sand-skull and tower sites intersect modpack villages in the played save. Their photographs do not certify collision-free placement. The author mined wood at the new World Tree site.

Exact source filenames, crop rectangles, dimensions and SHA-256 values are in [manifest.json](manifest.json). Historical public paths remain as compatibility copies; new references use this directory.

## Website slideshows

Both website languages group all 31 images by the `subject` in `manifest.json`.
After changing the library, run `python3 tools/update_website_gallery.py` from
the repository root to refresh both static galleries. The generator uses the
manifest's German/English titles and capture provenance; image files stay unchanged.
