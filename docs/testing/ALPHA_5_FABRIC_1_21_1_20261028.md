# Alpha 5.0 Fabric 1.21.1 verification, 28 October 2026

Artifact: `relics-0.1.0-alpha.5.0+mc1.21.1.jar`.
SHA-256: `79e72efc460df51391518b171239651730dd459929dfb942b080e8f09c0f1ae3`.

[Hash-bound evidence](alpha5-fabric-1.21.1-20261028-evidence.json) contains the
accepted native runs and their exact installed artifact hashes. Tests run on
Java 21 with the production remapped Fabric mod and separate validation code.

## Passed

- All 40 template hashes and six selection manifests, 94 Java 21 classes,
  required production mixins, no test classes or bundled dependencies.
- Forced recompilation/remapping produces identical bytes. Compilation from a
  separate staged Git export produces the same JAR. Its frozen resource input
  is the already verified Fabric 26.2 release bundle; all new Java adapters are
  compiled from the export. The original 26.2 JAR remains byte-identical.
- Native core processing stops after its two available operations and survives
  save/restart. Native maintenance recipes expose shaped ingredients/results,
  reject invalid charge states and preserve components. The furnace menu has
  working insertion/flame states. Native smithing applies the Monolith pattern.
- Two simulated players traverse native Trial/Vault states and receive personal
  physical drops. Keys are paid immediately; saved receipts and the original
  outstanding drop survive restart. Other players and hoppers cannot take rewards.
- Magnet motion reaches 0.385 blocks/tick, works in either selected hand and
  stays inactive in ordinary inventory. A stack of 64 costs 64 points. Partial,
  failed and final-budget pickups conserve items and account for wear correctly.
- The 80-block spherical Tree aura passes 51 boundary/eligibility/merge cases
  before and after restart, with Regeneration II, Resistance II and 6,000 ticks.
- Actual natural animal hooks produce bounded extras and charge the original
  SpawnState. Native global/local caps block extras. No independent spawn occurs.
- Five natural case records span eight starts: large/small Colossus, two Obelisk
  orientations, Tree, two Tower orientations and corrected Skull 2. Exact model
  cells, protected clearances, rotated markers, loot, archaeology/map targets
  and the removed side chip pass. Three starts of each test world preserve
  the selection and consumed loot is not refilled.
- Native map codecs preserve the same committed target and copied map IDs
  across actual reloads.

## Compatibility and coverage

Only generated 1.21.1 resources substitute firefly bushes with ferns and copper
reward chests with ordinary chests. The approved surrounding structures, authored
positions, loot and access remain. The recipe book, integer charge icons and trim
atlas use the older game's native formats.

Only matching, successful per-case records are accepted. Earlier compatibility
failures and two reads interrupted by a simultaneous rebuild are excluded.
The harness now snapshots its inputs before starting worlds.

This is actual server/asset evidence, not a new graphical two-client, shader/LOD
or arbitrary modpack acceptance. Earlier real-client approval applies to Fabric
26.2. Existing 1.21.1 visual worlds retain legacy selection; full Alpha 5 requires
a new native 1.21.1 world. Cross-version or cross-loader save conversion is not
provided by this release.
