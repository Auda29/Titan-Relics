## Client-resource correction

Alpha 5.0.1 removes the unavailable 1.21.1 `copper_darker` palette reference.
All 37 model, texture and palette references resolve against the actual 1.21.1
client JAR. Both Monolith masks use only opaque colors present in that game's
native trim palette. The first Fabric 1.21.1 Alpha 5.0 release is superseded.

The first tag's Linux build was reproducible but used the host zlib's different
gzip OS marker for the two derived Tree templates. The shared port encoder now
fixes that marker, with a cross-platform regression check. This retains the
validated geometry and prevents host metadata from changing derived template
hashes. Asset-reference and malformed/wrong-loader storage regressions also pass.

Server tests use simulated players. This report does not transfer the earlier
real-client acceptance on Fabric 26.2 to these new ports or claim shader/LOD and
arbitrary modpack acceptance. A fresh native 1.21.1 world is required for the
complete Alpha 5 selection; cross-loader save conversion is not provided.
