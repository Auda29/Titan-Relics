save/restart. Core processing, furnace/menu behavior, maintenance recipe-book
data and Monolith smithing pass 29 checks on restart. Trial and Vault progress
through their native states and send the expected event packets. Two simulated
players receive personal physical rewards. Successful Vault use pays the key
immediately; an uncollected core preserves its original entity identity and
payment/receipt state after restart.

The magnet attracts at maximum speed 0.385 in either selected hand. Three items
cost three uses and a full 64-item stack costs 64. Partial insertion, exhaustion,

merge cases before and after restart: Regeneration II, Resistance II and 6,000
ticks. Extra animals share natural spawn population accounting, obey local and
global caps, and do not spawn independently. Native finalization cancellation
creates no animal and charges no population.

Five fresh natural-world cases pass three starts each, including loot mutation
and no-refill verification. Eight saved starts cover both Colossi, two Obelisk
orientations, Tree, two Tower orientations and corrected Skull 2. Independent
saved-world comparisons verify model cells, clearances, protected routes,
markers, loot, archaeology, map origins/copies and the removed Skull side chip.
After the last restart, 450 chunks retain valid native protection sections and
no Fabric protection attachment. The modern MapCodec receipt wrapper also

## Build provenance and limits

A forced rebuild with the same toolchain produces the same JAR. A separate
staged Git export also builds byte-identically, using the already verified
original Fabric 26.2 resource bundle as its frozen resource input. Primary Java
and model sources, the original Fabric 26.2 release and both published 1.21.1
packages are preserved. The existing independent NeoForge 4.9 draft is excluded.

The separate export preserves every tracked resource blob exactly and uses the
frozen bundle only to supply generated resources. Regression coverage includes
161 test methods. Four methods initially rejected the export's packed JSON
formatting or missing final report; restoring the original Git resources and
final documentation resolves them. All seven focused source-byte/layout
rechecks pass with an actual zero subprocess exit code. A subsequent forced
build still produces the exact tested artifact; no test assertions were changed.

The earlier 1.21.1 Linux CI passes all checks, including 161 Python regressions
and reproducibility on that runner. Its port hashes differ from the published
Windows-toolchain packages; cross-toolchain byte identity is not claimed. The
NeoForge 26.2 CI adds its own build and same-toolchain reproducibility gates.

Tests use isolated worlds and simulated players. They do not transfer the
original Fabric 26.2 graphical/two-client acceptance to this new native port.
No launcher profile or player save was opened or changed. Use a fresh native
world for the complete selection; cross-loader save conversion is not provided.
